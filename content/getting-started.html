This section is a hub of resources grouped by topic. Pick one to go deeper.

  • Sense HAT API The pi4j-drivers Sense HAT driver — the igfasouza fork and the jar generator.
  • Sense HAT Emulator Run and test Sense HAT code without a physical board.
  • Astro Pi The programme that put the Sense HAT on the International Space Station.
  • JBang The single-file Java runner used by every example in this playground.
  • Jupyter Notebooks · coming soon Running Java + Sense HAT inside notebooks for teaching and experimentation.
  • Sense HAT AI · coming soon Integrations with AI models running on top of the Sense HAT.
